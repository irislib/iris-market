# Iris Market Core

Rust application core for Iris Market: signed marketplace listings, profiles, local storage, private messaging and orders over Nostr.

This crate is a development prototype. Private messages use the Iris Chat protocol and nostr-double-ratchet. The optional `cashu-wallet` feature enables native Cashu adapters; it is disabled by default.

See the [project documentation](https://github.com/irislib/iris-market) for architecture, platform builds and limitations. Licensed under MIT.
