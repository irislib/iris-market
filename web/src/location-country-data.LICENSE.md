# Offline country boundaries

Made with Natural Earth. The source map data is **public domain**, including
modified and redistributed versions. See the publisher's
[terms of use](https://www.naturalearthdata.com/about/terms-of-use/) and
[50m admin-0 documentation](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-countries-2/).
Primary authors: Tom Patterson and Nathaniel Vaughn Kelso, with Natural Earth contributors.

The bundled file derives from Natural Earth's **1:50m admin-0 map units**, v5.1.1.
Map units keep ISO-coded overseas regions separate, unlike the countries layer.
This is approximate cartographic coverage, not address, postal-service, legal
boundary or GPS-accuracy data. Small islands may be absent. Natural Earth uses
de facto boundaries. No political or delivery-service conclusion is inferred.

- Repository: `nvkelso/natural-earth-vector`
- Full commit: `9380cca83db5f9aef52d5e762765100745f84b27`
- [Immutable source file](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/9380cca83db5f9aef52d5e762765100745f84b27/geojson/ne_50m_admin_0_map_units.geojson)
- Source SHA-256: `b8d421aca6e9e08e8cdf09cc26af111cc3e0deba4fe915611d58ade71e8a4db0`
- Source bytes: `3179420`
- Bundled SHA-256: `07ad2d9dfe315c2a1d00a93c59994966593ec1bda80de475104a1bd10a078c5b`
- Bundled bytes: `1862110`

The transformation removes descriptive attributes, retains the source
`ISO_A2_EH` code, and rounds longitude/latitude to four decimal places. It retains
all 265 features, 1,628 polygons, 1,641 rings and 100,218 vertices; no geometric
simplification or island removal is performed. Four features with no supported
ISO alpha-2 code (`-99` or `XK`) retain their geometry with a null code, so lookup
returns unknown rather than assigning a neighbouring country. Polygon and hole
ordering remain unchanged. Territorial coding otherwise follows the source.

The runtime loads this bundled data only when requested. It returns unknown for
open water, unsupported or overlapping regions, and positions within 250 metres
plus the reported geolocation uncertainty of a mapped boundary. This guard is
conservative but cannot guarantee accuracy of the underlying 1:50m cartography.
Artificial date-line seams and omitted coast details can also return unknown.
The caller should preserve the existing selection and allow manual selection.
It sends no coordinates to an external service and stores no location history.

## Reproduce the bundled file

Run with Python 3 from the repository root. This verifies the pinned source hash
before transformation; ordinary application builds use the checked-in file and
do not download it. The generated bytes must match the bundled hash above.

```python
import hashlib, json, urllib.request
from pathlib import Path

commit = "9380cca83db5f9aef52d5e762765100745f84b27"
digest = "b8d421aca6e9e08e8cdf09cc26af111cc3e0deba4fe915611d58ade71e8a4db0"
url = ("https://raw.githubusercontent.com/nvkelso/natural-earth-vector/"
       + commit + "/geojson/ne_50m_admin_0_map_units.geojson")
with urllib.request.urlopen(url, timeout=25) as response:
    raw = response.read(4_000_001)
assert len(raw) <= 4_000_000 and hashlib.sha256(raw).hexdigest() == digest
countries = []
for feature in json.loads(raw)["features"]:
    code = feature["properties"]["ISO_A2_EH"]
    geometry = feature["geometry"]
    assert geometry["type"] in ("Polygon", "MultiPolygon")
    polygons = geometry["coordinates"]
    if geometry["type"] == "Polygon":
        polygons = [polygons]
    countries.append([
        None if code in ("-99", "XK") else code,
        [[[[round(x, 4), round(y, 4)] for x, y in ring]
          for ring in polygon] for polygon in polygons],
    ])
data = {"version": 1, "sourceCommit": commit,
        "sourceSha256": digest, "countries": countries}
output = (json.dumps(data, separators=(",", ":"), ensure_ascii=True) + "\n").encode()
assert hashlib.sha256(output).hexdigest() == "07ad2d9dfe315c2a1d00a93c59994966593ec1bda80de475104a1bd10a078c5b"
Path("web/src/location-country-data.json").write_bytes(output)
```
